# Video Assets

Place video files here.

## Required Files
- hero.mp4 - Hero section background video
- hero-poster.jpg - Video poster image (1920x1080px)

**Video specs**:
- Format: MP4 (H.264 codec)
- Resolution: 1920x1080px (Full HD)
- Length: 10-30 seconds recommended
- File size: Keep under 5MB if possible

**Poster specs**:
- Format: JPG
- Resolution: 1920x1080px
- Use a representative frame from the video
