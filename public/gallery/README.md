# Gallery Images

Organize gallery images by event in subfolders.

## Recommended Structure
```
gallery/
├── winter-meeting-2021/
│   ├── photo-1.jpg
│   ├── photo-2.jpg
│   └── ...
├── conference-2019/
│   └── ...
├── helping-babies-breathe/
│   └── ...
└── [event-name]/
    └── ...
```

**Image specs**:
- Format: JPG
- Featured images: 1200x800px
- Thumbnail images: 800x600px
- Compress for web
